User guide, version 1.7.2

How to use Questionnaire Autopilot.

Each section below covers one task. The steps come first, followed by a short video of the same steps in the app. The videos use Examplify Inc., a fictional company whose sample files are included with the app, so you can follow along before using your own files.

The videos have no sound. Windows that belong to your operating system, such as the file picker, are not shown in the videos: where a file is chosen, the video shows it appearing in the app.

Getting started

Install and uninstall

Your download is one ZIP named for your computer, for example QuestionnaireAutopilot-1.7.2-Windows-x64.zip. It contains the installer, a START HERE guide, these guides as files, the command line version and a checksum list.

Windows 10 and 11

  1. Open the ZIP and double-click QuestionnaireAutopilot-Setup-1.7.2.exe.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. This appears once because the installer is not yet code-signed.
  3. Keep the suggested folder and click Next. The app installs for your user account only and does not need administrator rights.
  4. Tick Create a desktop shortcut if you want one and click Next, then click Install.
  5. Click Finish. The app opens. Later, open it from the Start menu or the desktop shortcut.
  6. To uninstall, open Settings, then Apps, find Questionnaire Autopilot and choose Uninstall.

Linux

  1. On Ubuntu, Debian and similar systems, double-click the .deb file and click Install in the Software or App Center. Uninstall it from the same place.
  2. On other systems, right-click the .AppImage file, choose Properties, then Permissions, and allow it to run as a program. Double-click it to start. Delete the file to uninstall.
  3. On Linux the app opens in your web browser. It still runs only on your computer.

macOS

The macOS version is coming soon.

Your settings are kept when you uninstall. To remove them too, delete the folder %APPDATA%\Questionnaire Autopilot on Windows or ~/.config/Questionnaire Autopilot on Linux.

Activate your license

The first time the app opens, it asks for your license key. The key is in your purchase receipt email and on the My Orders page of Lemon Squeezy, under your order. One key activates up to three computers.

  1. Copy the license key from the receipt.
  2. Paste it into License key and click Activate. The computer must be online for this step.
  3. The app opens on the Start screen. The bottom of the menu shows the version and a License link.

Activation sends only the license key and a label for the computer, such as “Windows computer 3F2A9C”, to Lemon Squeezy. Your questionnaires, library and files are never sent. While the computer is online, the app confirms the license at most once a week. Without internet, it keeps working for 30 days after the last confirmation.

Move the license to another computer

  1. On the old computer, click License at the bottom of the menu.
  2. Click Deactivate this computer, then click it again to confirm.
  3. Activate the new computer with the same key.

If a computer was replaced or lost before you could deactivate it, email contactprautof@gmail.com with your order number. For computers without internet access, the email can ask for an offline license file: include the computer code shown under This computer has no internet access on the activation screen.

First run and the sample company

The Start screen opens first. The menu on the left lists every task.

  1. Open Questionnaire Autopilot.
  2. Click Start with the sample company. The app answers a 40 question sample questionnaire for Examplify Inc., a fictional company, using its sample library.
  3. Wait for the run to finish. The summary shows how many questions have a proposed answer and how many need a person.
  4. Click Review answers to look through the results. See Review and edit answers.

Appearance and quick actions

  1. Use the Dark mode switch at the bottom of the menu to change between dark and light. The app remembers your choice.
  2. Press Ctrl and K (Command and K on a Mac), or click Quick actions, to open the quick action list.
  3. Type part of a task name, for example "health", and press Enter to open it. Use the arrow keys to move through the list and Esc to close it.

Your approved answers

Create your answer library

Your library is one spreadsheet of answers your team has approved. The app only ever uses these answers.

  1. On the Start screen, click Create a new one under Your approved answers.
  2. The file my_approved_answers.csv is created in your results folder, and the folder opens.
  3. Open the file in Excel and add one row per approved answer, using the columns below. Replace the example row.
  4. Save the file as CSV or Excel. The Start screen now shows your library. To use a different file later, click Change.
ColumnWhat to enter
idA stable reference for the answer, for example ENC-001.
topicA short topic, for example Encryption.
questionThe question this answer responds to.
answerThe exact text your security owner approved.
evidence_refWhere the proof is kept, for example a policy section or audit report.
approved_by, approved_atWho approved the answer and the date, as YYYY-MM-DD.
expires_atOptional. After this date the answer is no longer used.
keywordsOptional. Extra words that help the app find this answer.
ownerOptional. The person or team who keeps the answer current.
applies_toOptional. The product, region or environment where the answer is true.
shareableOptional. yes only if the answer can go in a customer trust pack. Otherwise it stays private.

Build your library from past questionnaires

If your team has completed questionnaires before, recover those answers instead of typing them again.

  1. Open Build your library.
  2. Click the card and choose a completed questionnaire in Excel format (.xlsx or .xlsm).
  3. Click Recover answers. The answers are saved to approval_candidates.csv in your results folder.
  4. Open that file in Excel. For each answer you accept, set decision to APPROVED and fill in approved_by, approved_at and evidence_ref.
  5. Use the file as your library. Rows that are not marked APPROVED are never used.

Check library health

Check the library itself before a busy period, and whenever answers change.

  1. Open Library health and choose your library.
  2. Click Check library.
  3. Read the counts: active, shareable, expiring within 30 days, expired, and set aside.
  4. Work through each note. Renew expired approvals, resolve answers that contradict each other, and fix rows that were set aside.

Guard terms

Guard terms are words your team wants treated like certifications, such as a regulation or a service level. An answer that uses one is only accepted if your approved answers support it.

  1. Create a text file named guard_terms.txt in the same folder as your library.
  2. Write one term per line. Lines that start with # are ignored.
  3. Open Library health and click Check library. The terms found are listed under the notes.
  4. From now on, an answer that uses a guard term your approved answers do not support is marked At risk, in review and in the check before sending.

The library atlas

The Start screen shows your approved answers as an atlas. Each point is one answer, and answers on the same topic sit together in a band with the topic name beside it.

  1. Drag the atlas to turn it.
  2. Point at an answer to see its question. Click it to open a card with the full answer, its evidence reference, who approved it and when, its expiry date, whether it is shareable, and how many questions in the last run used it.
  3. Click Ask Intellinaire on the card to open the chat with a question about that answer. See Intellinaire, the assistant.
  4. Click a topic below the atlas to show only its answers. Click it again to show all.
  5. Type in Find an answer to highlight every answer that contains the text.
  6. Use the + and − buttons to zoom, or hold Ctrl and scroll. The last button resets the view.

Expired answers are drawn as rings and answers set aside are drawn smaller and grey. During a run, each question travels to the answers it used, in the colour of its result.

Answering questionnaires

Answer a questionnaire

  1. Open Answer a questionnaire.
  2. Click the first card and choose the buyer's questionnaire, in Excel or CSV format, exactly as they sent it. It needs a column named like Question, Requirement or Control.
  3. Click the second card and choose your approved answers.
  4. Check Save results in. Click Change to choose another folder.
  5. Click Answer questionnaire and wait for the run to finish.
  6. Click Open report to see every question with its status and evidence, or Review answers to work through them in the app.

Each question receives one status:

StatusMeaningWhat to do
MatchedYour approved answer, copied word for word.Check that it fits the buyer's wording.
DraftedWritten by the AI model from approved evidence and checked. Only with AI drafting on.Read it against the cited evidence.
SuggestedRelated approved answers were found, but no draft was written.Pick or combine the suggested answers.
Needs evidenceNo approved answer covers the question. Nothing was made up.Ask the owner for an approved answer and add it to your library.
Legal reviewA contract, liability or legal question. Never drafted.Send it to whoever owns contracts.
FlaggedThe cell contains instructions or a formula, so it was not processed.Read the cell yourself and answer it.
Draft blockedAn AI draft claimed more than the evidence says, so it was discarded.Write the answer from the listed evidence.

The results folder contains a filled copy of the buyer's workbook (the original is never changed), the review report, a review queue and a list of missing evidence.

Review and edit answers

  1. Open Review and edit, or click Review answers after a run.
  2. Use the filters (All, Needs a person, Drafted, Matched, Edited) or type in the search box to find questions.
  3. Select a question. Its answer appears beside the approved evidence it comes from.
  4. Edit the answer. The verdict under it updates as you type.
  5. Use Use approved wording to put back the approved text, Clear to empty the answer, or Revert to original to undo your edits.
VerdictMeaning
Approved wordingExactly your approved answer.
ConsistentEdited wording that stays within your approved evidence.
Not in libraryNothing in your library covers the answer, so it cannot be checked.
Legal to confirmA legal or contractual question has an answer. Confirm counsel approved it.
At riskThe answer claims something your approved answers do not support.
UnansweredNo answer has been entered yet.

Export the final file

  1. In Review and edit, click Export final file.
  2. The app writes final_answers.csv in a folder named final. For an Excel questionnaire it also writes final_questionnaire.xlsx, a copy of the buyer's workbook with your final answers. The buyer's original file is never changed.
  3. Every answer is checked once more. The result says whether the file is ready to send and lists anything to fix.
  4. Send the final file to the buyer yourself. The app never sends anything.

Check before sending

Use this for a final file that was edited outside the app, for example by colleagues in Excel.

  1. Open Check before sending.
  2. Choose the final questionnaire and your approved answers.
  3. Click Run the check.
  4. Fix every answer marked At risk, then run the check again until the file is ready to send.
  5. Click Open pre-send report to keep a record of the check with the questionnaire. New wording your team wrote is saved to library_candidates.csv, ready to approve into your library.

Sharing with customers

Customer trust pack

A trust pack is a security overview page for customers, built only from answers you mark as shareable.

  1. In your library, set shareable to yes for each answer that is safe to share.
  2. Open Customer trust pack, choose your library and enter your company name as customers know it.
  3. Click Build trust pack. Private and expired answers are left out automatically.
  4. Click Open trust pack and read it before sending it. The page works offline and makes no network requests.

Intellinaire

AI drafting is optional. Without it, answers come only from your library. With it, questions that only partly match your library get a drafted answer, written from the approved answers it cites. Every draft is checked against those answers before you see it, and a draft that claims more is discarded.

AI on your computer

A model on your own computer keeps every question on that computer. You can use llama.cpp, Ollama or LM Studio.

  1. Start the model server. For example: ollama run llama3.2 for Ollama, the local server in LM Studio, or llama-server -m your-model.gguf --host 127.0.0.1 --port 8089 -c 8192 for llama.cpp.
  2. In the app, open AI drafting and choose the matching card under On this computer.
  3. Check the Address of the server. Enter the model name, or click Load list and choose one.
  4. Click Test connection. The model answers one test question.
  5. Click Use this model. Your next questionnaire is answered with drafting on.

Drafting speed depends on your computer. While the model writes, the video plays at five times normal speed and says so on screen.

AI with a cloud service

You can use your own key for OpenAI, Anthropic, Google Gemini, Mistral, Groq, OpenRouter or another OpenAI-compatible service. Only the question and up to three matching approved answers are sent, and only after you allow it.

  1. Open AI drafting and choose the service under Cloud services.
  2. Paste your API key and click Save key. The key is stored on this computer only, encrypted with your Windows account on Windows. You can also set it in an environment variable, such as ANTHROPIC_API_KEY.
  3. Enter the model name, or click Load list and choose one.
  4. Tick the box that allows sending questions and matching approved answers to that service.
  5. Click Test connection, then Use this model.
  6. To remove a saved key, click Forget saved key.

No key is entered in this video, and nothing is sent.

Turn AI drafting off

  1. Open AI drafting. In use now shows the model that drafts answers.
  2. Click Turn off AI. From now on, answers come only from your approved library.

Intellinaire, the assistant

Intellinaire is the assistant built into the app. It answers questions about the app and your work, prepares changes for you to approve, and helps with anything else, such as writing, analysis or code. It uses the model you set up on the AI drafting page, on your computer or in the cloud.

  1. Set up a model on the AI drafting page. See AI on your computer or AI with a cloud service.
  2. Open Chat under Intellinaire in the menu, or click Ask Intellinaire near the bottom of the menu on any page. You can also press Ctrl, Shift and I.
  3. Type a question in the message box and press Enter. Press Shift and Enter for a new line.
  4. Each step Intellinaire takes, such as reading the review list or searching your library, is listed above its reply. Click a step to see what it read.
  5. Ask a follow-up question in the same conversation. Intellinaire keeps the context of the whole conversation.
  6. To stop a reply, click the red stop button. Point at a reply to copy it or have it written again. Point at your own message to edit it and send it again.

Intellinaire knows which page you came from and which question you had selected on the Review page, so a question such as "Improve this answer" refers to that question.

The circle next to the model name shows how much of the model's memory the conversation uses. When it fills up, older messages are summarised automatically, so long conversations keep their context.

Changes and approvals

Intellinaire can prepare these changes: a new answer for a question in the review, a new or updated answer in your library, guard terms, settings such as the company name or appearance, and tasks such as running the sample company or building the trust pack. It never makes a change by itself.

  1. Ask for the change, for example "Improve the answer to Q12 using only approved evidence" or "Add Salesforce to the guard terms".
  2. A Proposed change card appears in the reply. For an answer, it shows the new wording marked against the current answer and the claim guard's verdict.
  3. Click Approve to apply the change, or Reject to leave everything as it is.
  4. The card then shows what was done. For an answer edit, export the final file from the Review page to write it to the buyer's file.

Library changes work with CSV libraries. Before a library file is changed, the previous version is saved beside it with the date and time in its name.

Files, images and web search

  1. To attach a file, click the paperclip button, drag the file onto the chat, or paste it. Excel, Word, PDF, CSV, text and code files up to 8 MB can be attached.
  2. To attach an image, click the picture button, drag it in, or paste a screenshot. Models that accept images can read it.
  3. To let Intellinaire search the web for one message, click Search the web before you send. Sources it used are listed under the reply. Click one to open it in your browser.
  4. For full web results, open Chat settings (the button at the top right of the chat) and add a Brave Search or Tavily API key. Without a key, a basic search is used. Claude models use their own web search.

With a cloud model, the app asks once for your permission before the first message. Your messages, attached files and the app details Intellinaire reads are then sent to that service. You can withdraw the permission in Chat settings. API keys are never sent to a model.

Manage conversations

  1. Click New chat at the top of the conversation list, or press Ctrl, Shift and O.
  2. Conversations are grouped by date: Today, Yesterday, Previous 7 days, Previous 30 days and Older. The date and time of the last message is shown under each title.
  3. Type in Search conversations to find one by its title or last message.
  4. Point at a conversation and click the three dots to Rename it, Pin it to the top, Copy as Markdown, or Delete it. Delete asks you to confirm.
  5. To use a different model for one conversation, click the model name at the top right and choose another. Models are set up on the AI drafting page.

Conversations and attached files are stored on your computer only, in the chats folder inside the settings folder.

While the model writes, the video plays at five times normal speed and says so on screen.

More

Command line

Every task is also available as a command, for scripts and scheduled jobs. The command line is part of the installed app and uses the same license, so activate the app first.

  1. Open a terminal. On Windows, open a new Command Prompt or PowerShell window after installing; the installer adds qa to your path.
  2. Run qa self-test to confirm everything works. On Linux, use questionnaire-autopilot in place of qa after installing the .deb, or the path of the AppImage file.
  3. Run the command for the task you need, from the table below. Each command writes its results to the folder given after --out.
CommandWhat it does
qa self-testRuns the 22 built-in checks.
qa demoRuns the fictional sample company.
qa init-library my_answers.csvCreates a library from the template.
qa check-library my_answers.csvChecks library health.
qa import-history done.xlsx --out approval_candidates.csvRecovers answers from a completed questionnaire.
qa run incoming.xlsx --library my_answers.csv --out out/acmeAnswers a questionnaire. Add --provider and --model for AI drafting, and --allow-cloud for a cloud service.
qa check-final final.xlsx --library my_answers.csv --out out/checkChecks the final file. Exits with code 3 while anything is at risk.
qa build-trust-pack --library my_answers.csv --company "Your Company" --out trust-packBuilds a customer trust pack.
qa license statusShows the license of this computer. qa license activate KEY activates it, qa license deactivate releases it.

The video shows these commands with the output they printed when run on the sample files.

Troubleshooting

  1. The app shows "Part of the app was blocked from loading". An ad blocker or web filter, such as AdGuard, is filtering the app's local connection. In that program, allow 127.0.0.1 or add Questionnaire Autopilot to its exclusions, then reopen the app.
  2. Windows shows "Windows protected your PC". Click More info, then Run anyway. This appears once.
  3. The AppImage does not start on Linux. Install the libfuse2 package (libfuse2t64 on Ubuntu 24.04 and later), or use the .deb file.
  4. Activation says the key is already active on three computers. Deactivate one of them under License, or email contactprautof@gmail.com if that computer is no longer available.
  5. The app asks to confirm the license. It has not reached the license service for 30 days, or the computer's date was changed. Connect to the internet, open License and click Check now.
  6. Test connection fails for a local model. Make sure the model server is running and that the address in the app matches its port.
  7. A question you expected to match is Needs evidence. Add the buyer's wording to the keywords column of the matching library row, or add a new approved answer.
  8. Anything else. Email contactprautof@gmail.com with your operating system and what you saw. If we cannot make the app work on your computer, you get a refund within 14 days of purchase.
